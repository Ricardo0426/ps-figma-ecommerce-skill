# Change log

## 2026-11-15

Updated guidance from the V10 Pro Russian ecommerce/Figma project:

- Separate target-language copy from translation/reference text in mixed-language requirement sheets, and respect missing image numbers and current output dimensions.
- Use a completed user-approved hero as a style reference while recording per-format/per-page exceptions.
- Reflow target-language typography using the actual target copy instead of shrinking a whole set to fit another language’s frames.
- Preserve source art as a separate reference when rebuilding for a different delivery aspect ratio.
- Treat accessory count and full-subject preservation as separate checks when selecting or cropping real product assets.
