# PS → Figma 还原偏差修复

用于已有还原稿与 PS 外观明显不一致的续修。读取本轮目标画板、源图层描述和现有 Figma 结构，先定位偏差来源，再决定改字、换素材、补合成依赖还是调整层序。本文记录的是实际项目中的故障模式；API 行为仍须在当前工具/版本验证。

## 确认还原目标和映射

- 同尺寸外观还原以指定 PS 画板的最终渲染为对照；换语言、改画幅或重新设计按当前需求另行排版，不能把两者混作一个验收目标。
- 按源文档、画板、图层 ID 和 Figma 节点建立对应。画板名、语言组和导出序号可能反向或错位，不仅凭名称/顺序配对。PS 文档 ID 属于运行期，重开后重新读取。
- 保留 `native` 原始内容与 `display/derived` 外观资产：前者提供最高可用信息，后者可包含已确认的图层效果和必要合成。取出高分辨率智能对象并不自动保留 PS 最终调色、阴影和剪贴外观。
- 字体策略依用户要求和当前工程确定。替换字体即使字号/宽度接近也可能有轮廓、字重和行高差异；不能把某项目的固定字体推广为所有项目标准。

## 文字：区分原始字号、变换后的字号与可见字形

旧脚本若只读取 `textItem.size`，会漏掉文字图层缩放。出现标题放大、行距异常或压住正文时，先检查 PS 描述，而不是把所有文字一起缩小。

1. 用可用的只读接口获取 `textKey.transform`、`textStyleRange`、各段字体/字号/斜体和 leading；有 `impliedFontSize`、`impliedLeading` 时优先核对它们。混合样式不能只取第一段。
2. 确认字段单位与源文档分辨率；以 pt 表达时才按 `px = pt × dpi / 72` 换算。实际字号可能已经包含 transform，不再重复乘缩放矩阵。字段缺失、非等比变换或结果可疑时，用 PS 的可见字形尺寸复核。
3. 在 Figma 先设置实际字体、字号、行距和框宽，再读回布局框尺寸，最后定位；设置样式会触发 reflow，旧高度不能直接沿用。
4. 分清 TEXT 布局框、PS 可见字形 bounds 和单节点导出图裁切框。导出可能裁掉字形周围空白，不能把 PNG 宽高直接回写为文本框宽高；测量时保留裁切偏移。
5. 原生 TEXT 的渐变可按 PS 实际标题效果取样拟合，核对方向、色标与字形范围。拟合渐变和字体替换都有误差，不宣称像素级一致。

多语言组共用图形结构时，素材修复可以共享，但文字需用各自最终文案重新测量。逐节点检查长标题、按钮和说明的行高/可读性；单纯落在框内不等于阅读验收通过。

## 素材：真实 alpha、效果与源位置

- 浅色像素不是背景。不要以“合并拷贝 + 去白”代替透明导出，否则会损坏白色产品细节、光晕和半透明边缘。
- 精确还原需记录源选区/导出矩形、画板偏移、素材 alpha bbox 及其在矩形内的位置。去透明边距后必须补偿节点位置或图片变换，不能直接铺满旧矩形。
- PS 合并拷贝后粘贴到新文档可能按非透明像素居中。即使导出尺寸正确，可见主体仍可能偏移；至少选一个有明显透明边距的素材实测后再批量。优先使用能保留画布坐标的导出方式。
- 若当前路径确实有自动居中，可在临时副本的已知导出边界加入低透明定位像素，再导出并只删除这些已知辅助像素。一次已验证的修复使用了四角约 1% 不透明定位，但这只是备选方法，不是通用参数；角落含真实内容时应另选方法，不能全图阈值去除低 alpha。
- 素材记录哪些效果、opacity、剪贴基底或混合已经合成。保留源图层渲染与原始内容两个用途，避免导入后重复施加同一透明度/效果。

## PS 导出时保护画板与剪贴状态

只在当前工具没有合适的原生导出能力时补脚本，先在临时副本/单画板验证。不要把历史项目脚本直接当通用提取器。

- 修改画板背景应使用经当前版本验证的画板专用能力。使用 ActionManager 的 `editArtboardEvent` 的实测案例需要先激活目标画板；不能仅传某个引用就假设每块画板都已更新。
- 曾有以普通组 `setd` 写画板属性的脚本触发画板转组及画布偏移。发现画板类型/坐标变化立即停止该路径，恢复现场后改用已验证的方法。
- 临时隔离图层时，显式记录并在结束/异常恢复 visibility、画板背景和活动目标，不只依赖 history 回退。恢复外观不表示撤销历史记录或清除未保存状态；不要覆盖保存唯一 PS 源稿。
- 保留剪贴依赖和必要基底，不无条件设置 `grouped=false`。解除剪贴或隐藏基底可能造成空白、色差或范围变化。导出失败时先读当前状态，再补缺项。

## Figma 蒙版、层序与混合

- PS 有色剪贴基底既参与裁切又可能可见，Figma mask 只承担遮罩语义时会丢掉这部分底色。出现底条/色块消失时，检查是否需要额外的可见基底；可见副本不作为 mask，原蒙版继续裁切，并按实际遮挡关系放置。
- 可见基底与已合成资产同时存在时检查半透明重复叠色。已经把某混合及其依赖烘焙进图片的资产，应按单次合成显示；常见做法是使用 NORMAL 并核对 opacity。仍依赖现场背景的素材不能一律改 NORMAL。
- 按 PS 原始相对遮挡关系映射层序。不要把所有剪贴组统一塞到底部或固定 `index 2`；背景、画板范围 mask 和局部剪贴组要分别识别。
- `clone/reparent` 后读取返回 ID、parent、位置、尺寸和 transform。曾遇克隆嵌套矩形落到 x/y=0；需要时显式定位，不能假定所有工具版本都会保位或都会归零。批量前先测一个。
- 复杂曲线/图层效果可以在独立容器中用透明图片保持外观；交接应称其为可替换的栅格填充。RECTANGLE 容器或可拖动分层不等于原生可编辑矢量。正式文案仍用 TEXT。

## 对照与证据范围

- 对发生变化的画板保留 PS / 修改前 / 修改后三列对照，统一导出尺寸、裁切、色彩空间及 alpha 合成底色。记录所对应的轮次、时间和目标组，不能用中间预览代表最新全文件。
- MAE 等像素差异适合辅助定位/排序，须记录预处理方式；它不是“相似度百分比”，也不能证明俄语文案正确、文字可读或验收完成。
- 原尺寸检查文字、边缘、透明度、阴影及遮挡，缩略图检查层级。几何检查、差异数值与人工视觉检查分别记录。
- 暂停现场若出现其他页面/节点，只记录已观察的范围，不推断作者、不按旧结构删除新增内容，也不把原有修复组的检查结论推广成全文件通过。暂停归档按 [delivery-and-xlsx.md](delivery-and-xlsx.md) 执行。
